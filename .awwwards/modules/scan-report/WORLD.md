# World

Module: standalone HTML report of the accessibility scan (scanner/src/report/, sample at scanner/sample-report.html). Host route of the site: /skaner/ (the form that orders the report), neighbour /uslugi/dostepnosc-wcag/. The report itself is served from R2, not from Gatsby.

## Stack and engine

Site: Gatsby (React), CSS files in src/styles, framer-motion 13 for reveal and split text, CSS transitions for the tape and ticket, Lenis-free native smooth scroll. Report: generated by scanner/src/report/index.js (tagged template with escaping in escape.js), CSS inline in styles.js. CSP default-src 'none'; img-src data: https:; style-src 'unsafe-inline'. So the report has no JS and no engine at all. Motion, if any, is CSS transform and opacity with the site's ease cubic-bezier(0.2, 0.8, 0.2, 1) and always gated by prefers-reduced-motion.

## Tokens

Source: src/styles/global.css :root. Colours: wool #5a1424, wool-deep #3b0d18, chalk #e9eff6, chalk-dim #c3cedd, chalk-blue #9dbbe0, paper #cbd3da, ink #14181f, ink-soft #2f3743, thread #8e1226. Amber #f0b840 is used on the site for measured numerals. Type: display Bespoke Serif (heavy bookish serif, headlines, tight), text Schibsted Grotesk, hand Mynerve (annotations, only decorative and aria-hidden). Motion tokens: src/motion.js ease.out [0.2,0.8,0.2,1], draw [0.4,0,0.2,1], durations reveal .85, stitch .4, thread 1.5. Radius: nearly none (2px), edges are cut, notched or pinked (tooth-up and tooth-down SVG), grain overlay on wool.
Report fonts: web fonts are not available (CSP default-src none, no external resources). The report uses fallbacks only: Georgia for display, system-ui for text, Segoe Script / Bradley Hand for the hand. This is a documented fallback of the existing fonts, not a new font. The report paper colour is warm off-white #f6f3ee while the site paper is cool grey #cbd3da: a deliberate print-friendly adaptation, tag and masthead use wool and chalk.
